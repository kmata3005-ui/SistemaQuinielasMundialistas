# Cruces automáticos

Esta versión incorpora una fase eliminatoria calculada a partir de las tablas de posiciones.

## Flujo

1. Los grupos A, B, C y D calculan sus dos primeros lugares.
2. Se generan cuatro partidos de cuartos de final:
   - A1 vs B2
   - B1 vs A2
   - C1 vs D2
   - D1 vs C2
3. Cuando los cuatro cuartos están finalizados y tienen ganador, se crean dos semifinales.
4. Cuando las dos semifinales están finalizadas y tienen ganador, se crea la final.

## Uso

- Abra el módulo **Cruces**.
- Pulse **Generar / actualizar cruces**.
- Los resultados se registran en el módulo **Partidos**.
- Use la fecha simulada para poner los encuentros en curso y finalizarlos.
- Regrese a **Cruces** y pulse actualizar para generar la ronda siguiente.

## Regla importante

Un partido eliminatorio no puede terminar empatado para avanzar. Si queda empatado, el sistema solicita definir un ganador modificando el marcador.
