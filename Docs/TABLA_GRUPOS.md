# Tabla de posiciones por grupos

La pantalla **Grupos** calcula automáticamente la clasificación usando únicamente partidos que tengan un valor en la propiedad `Grupo` y cuyo estado sea `Finalizado`.

Criterios aplicados:

1. Puntos.
2. Diferencia de goles.
3. Goles a favor.
4. Nombre del equipo.

Puntuación: victoria 3 puntos, empate 1 punto y derrota 0 puntos. Los dos primeros lugares aparecen marcados como clasificados.

El sistema agrega datos simulados para los grupos A, B y C solamente cuando todavía no existen partidos de grupos. Los partidos y pronósticos anteriores no se eliminan.
