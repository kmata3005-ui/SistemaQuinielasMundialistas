# Penales y avance automático

Esta versión permite resolver empates en partidos eliminatorios mediante una tanda de penales.

## Uso

1. Finalice un partido eliminatorio con marcador empatado.
2. Abra el módulo **Cruces**.
3. Seleccione el partido empatado.
4. Indique los goles por penales del equipo local y visitante.
5. Presione **Definir ganador por penales**.
6. El ganador queda registrado y, cuando toda la ronda tiene ganador, se genera automáticamente la siguiente fase.

La tanda debe tener un ganador; no se aceptan valores empatados.
